# Agent Instructions — Music Universe

## Goal
Build a polished 3D graph of artists, tracks, and genres.

## Rules
1. Inspect the repository before changing it.
2. Read `PRD.md`, `tech.md`, `architecture.md`, `data-model.md`, and `implementation-plan.md`.
3. Preserve existing working conventions; avoid unnecessary config replacement.
4. Implement in small milestones and run checks after meaningful changes.
5. Never claim a test/build passed unless actually run.
6. Distinguish demo, provider-sourced, and derived data.
7. Never invent Spotify capabilities, play counts, similarity, or permissions.
8. Never put client secrets in frontend code or commit credentials.
9. Prefer accessible, maintainable code over needless abstractions.
10. Avoid expensive per-node lights, excessive post-processing, and per-frame React state updates.
11. Do not add unrelated features without updating docs.
12. Update docs when decisions or limitations change.

## Completion report
Report changed files, features, commands actually run and outcomes, known limitations, and the next milestone.
