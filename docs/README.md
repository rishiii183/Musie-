# 3D Music Universe — Documentation Pack

This pack defines the product, technical stack, architecture decisions, graph model, implementation milestones, and coding-agent rules.

- `PRD.md` — product vision, scope, interactions, success criteria.
- `tech.md` — stack, structure, data model, rendering, security, and tests.
- `architecture.md` — key decisions and trade-offs.
- `data-model.md` — graph nodes, edges, provenance, invariants.
- `implementation-plan.md` — execution milestones.
- `AGENTS.md` — instructions for an AI coding agent.

## Recommended first step
Build the complete sample-data universe before Spotify integration.

Typical Vite commands once the app exists:
```bash
npm install
npm run dev
npm run build
```
These are recommended commands; they have not been run against an application yet.
